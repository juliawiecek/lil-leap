NEXTTRADE QUOTE API - RUN AND TEST

Place these files under lil-leap/data-pipeline as described in the chat.
Keep your existing src/generate_quotes.py and tests/test_generate_quotes.py.

From lil-leap/data-pipeline in Git Bash:

1. Activate the environment:
   source .venv/Scripts/activate

2. Install the new Flask dependency:
   python -m pip install -r requirements.txt

3. Run every test:
   python -m pytest -v

4. Start the API:
   python -m src.app

5. In a second terminal, test:
   curl http://localhost:8080/health
   curl http://localhost:8080/api/v1/quotes/AAPL
   curl http://localhost:8080/api/v1/quotes/AAPL
   curl http://localhost:8080/api/v1/quotes/NOTREAL

The second AAPL response within five seconds should contain:
   "cached": true

The unsupported symbol should return HTTP 404 with:
   "code": "QUOTE_NOT_FOUND"

Docker test:
   docker build -t nexttrade-quote-api .
   docker run --rm -p 8080:8080 nexttrade-quote-api
