NextTrade Java API documentation

Generated Javadoc for the production Java APIs. Each service has its own site because the services share some package and class names.

  • Insights — portfolio queries, order submission, execution queue and quote policies, instruments, authentication and password reset.
  • Orders — scheduled execution, quotes, fills, settlement ledger entities and shared onboarding APIs.
  • Holdings — shared starter APIs; dedicated holdings business logic is not implemented in this service.
Insights snapshot: the working tree currently deletes OrderSufficiencyException.java while production code still references it. The Insights HTML was generated in a temporary source copy with that class from HEAD. Regeneration from the working tree requires resolving that missing type.

From the repository root, regenerate with JDK 21, Maven and Python 3:

python scripts/generate_javadocs.py

The script validates all three services before replacing these HTML snapshots. To browse over HTTP, run python -m http.server 8000 --directory docs/javadoc and open localhost:8000.
