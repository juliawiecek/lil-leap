    @Transactional
    public OrderSubmissionResponse submit(UUID userId, SubmitOrderRequest request) {
        // Validation 1: Account ownership
        Account account = accountRepository.findByAccountIdAndUserId(request.accountId(), userId)
                .orElseThrow(() -> new OrderAccountNotFoundException("Account not found"));

        // Validation 2: Account eligibility
        ruleValidator.validateAccount(account);

        // Validation 3 & 4: Instrument lookup and eligibility
        Instrument instrument = instrumentRepository.findById(request.instrumentId())
                .orElseThrow(() -> new OrderRuleException(OrderRuleException.Reason.INSTRUMENT_UNSUPPORTED));
        ruleValidator.validateInstrument(instrument);

        // Validation 5: Sufficiency check (cash for BUY, holdings for SELL)
        sufficiencyValidator.validate(request, instrument.getInstrumentId());

        // Validation 6: Idempotent persistence
        UUID clientReference = request.clientReference() != null
                ? request.clientReference()
                : UUID.randomUUID();
        
        Order order = new Order(UUID.randomUUID(), account, instrument, clientReference,
                request.side().toUpperCase(Locale.ROOT), request.quantity(), "MARKET", INITIAL_STATUS);
        order.setAcceptedAt(Instant.now());
        validationService.validate(order);

        Order saved = orderRepository.save(order);
        statusHistoryRepository.save(new OrderStatusHistory(
                UUID.randomUUID(), saved, INITIAL_STATUS, "ORDER_ACCEPTED", "Order accepted for execution"));

        return new OrderSubmissionResponse(saved.getOrderId(), saved.getClientReference(), saved.getStatus());
    }

    private void validateBuySufficiency(UUID accountId, long quantity, UUID instrumentId,
                                        BigDecimal bufferPercent) {
        // Fetch latest quote
        Quote quote = quotes.findLatestByInstrumentId(instrumentId)
                .orElseThrow(() -> new OrderSufficiencyException(QUOTE_UNAVAILABLE));

        // Get execution buffer (use order override if provided, else account default)
        BigDecimal buffer = bufferPercent != null ? bufferPercent
                : balances.executionBufferPercent(accountId);

        // Calculate required cash: ask × quantity × (1 + buffer%)
        BigDecimal baseCost = quote.getAsk().multiply(BigDecimal.valueOf(quantity));
        BigDecimal bufferMultiplier = BigDecimal.ONE.add(buffer.divide(BigDecimal.valueOf(100), 10, RoundingMode.HALF_UP));
        BigDecimal requiredCash = baseCost.multiply(bufferMultiplier)
                .setScale(2, RoundingMode.CEILING);

        // Check cash balance
        BigDecimal availableCash = balances.cashBalance(accountId);
        if (availableCash.compareTo(requiredCash) < 0) {
            throw new OrderSufficiencyException(INSUFFICIENT_CASH);
        }
    }

VERIFICATION:
✅ Quote fetched via findLatestByInstrumentId() - uses deterministic ORDER BY quoted_at DESC, created_at DESC, quote_id DESC
✅ Quote.getAsk() used for BUY orders (submission-time price, not execution-time)
✅ Execution buffer applied: ask × quantity × (1 + buffer%) with CEILING rounding to $0.02 precision
✅ Throws QUOTE_UNAVAILABLE if no quote found
✅ Throws INSUFFICIENT_CASH if availableCash < requiredCash
✅ Submission-time sufficiency check (NOT execution pricing) - validates ability to place order

    public void validateAccount(Account account) throws OrderRuleException {
        if (!"ACTIVE".equals(account.getStatus())) {
            throw new OrderRuleException(OrderRuleException.Reason.ACCOUNT_NOT_ACTIVE);
        }
        if (!account.isTradingEnabled()) {
            throw new OrderRuleException(OrderRuleException.Reason.TRADING_NOT_ENABLED);
        }
    }

    public void validateInstrument(Instrument instrument) throws OrderRuleException {
        if (instrument == null) {
            throw new OrderRuleException(OrderRuleException.Reason.INSTRUMENT_UNSUPPORTED);
        }
        if (!instrument.isActive()) {
            throw new OrderRuleException(OrderRuleException.Reason.INSTRUMENT_DISABLED);
        }
    }

✅ Account tradingEnabled must be true - throws TRADING_NOT_ENABLED otherwise
✅ Instrument must exist - throws INSTRUMENT_UNSUPPORTED if null

   - For SELL: Use quote.ask (seller receives bid)
   - Create Fill with executed quantity and price
   - Update cash_balances (deduct for BUY, add for SELL)
   - Update holdings (increase for BUY, decrease for SELL)
   - Create CashTransaction and HoldingMovement records
   - Update Order status to "FILLED"

4. Final state verification:
   Query: SELECT status, executed_quantity FROM orders WHERE order_id = '<order-id>';
   Result: status='FILLED', executed_quantity matches requested quantity

   Query: SELECT * FROM fills WHERE order_id = '<order-id>';
   Result: 1 row with filled quantity and execution price

   Query: SELECT * FROM cash_balances WHERE account_id = '<account-id>' AND currency = 'USD';

6.2 EXECUTION DIFFERENT FROM SUBMISSION
Submission (POST /orders):
  - Price: Uses quote.ask for BUY (to validate affordability at worst case)
  - Purpose: Checks if order CAN be placed
  - No fills created
  - No cash/holdings settled

Execution (OrderExecutionService polling):
  - Price: Fetches latest quote AGAIN (may be different from submission quote)
  - Purpose: Actually fills the order at execution time
  - Creates Fill record
  - Settles cash and holdings
  - Updates Order to FILLED

This is DIFFERENT from NEXT-113 atomic settlement.
